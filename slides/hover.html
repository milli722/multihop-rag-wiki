先備知識

開始前，先懂兩個名詞

事實查核 Fact Verification

給系統一句說法（claim），它要：

  • 去找證據
  • 判斷說法是否被證據支持

典型流程：說法 → 找證據 → 判斷

多跳推理 Multi-hop Reasoning

要串起好幾份證據才能判斷，而且後面的證據常常要靠前一份提供的線索才找得到。

跳數（hop）＝需要的證據文件數

先備知識 · 例子

多跳長什麼樣子？

說法：「1997 年 CART 賽季的年度新秀開的車款，是 2006 年式推出的。」

第 1 跳查「1997 CART 賽季」
→ 年度新秀是 Patrick Carpentier
→
第 2 跳查「Patrick Carpentier」
→ 他開 Ford Fusion
→
第 3 跳查「Ford Fusion」
→ 2006 年式推出 ✅
關鍵：原句裡完全沒提到「Ford Fusion」，光看原句幾乎找不到第 3 篇。要先找到前一篇，才知道下一篇要查什麼。

② 動機：為什麼要做

現有資料集，測不出真正的多跳能力

真實需求

社群媒體讓不實訊息變多，需要能自動找證據、再查證的系統

FEVER 太單跳

87% 以上的說法只要一篇 Wikipedia 文章就能查證

多跳 QA 可走捷徑

HotpotQA 等最多 2～3 篇，而且單跳模型也能拿到好成績 → 靠字詞比對就夠

👉 字詞比對的「捷徑」reasoning shortcut 讓模型看起來會多跳，其實沒有。

③ 欲解決的問題

理想的多跳題目應該長怎樣？

至少有一篇證據，光用說法本身做語意比對是找不到的；
必須先找到前一篇文件，從中得到線索，才能找到下一篇。

所以作者要的資料集有兩個條件：

  • 證據來自最多 4 篇文章
  • 說法和部分證據字面上不像（降低語意重疊）
④ 研究方法：怎麼做

三階段造資料

1. 說法建立把 HotpotQA 的問答改寫成 2-hop 說法，再「替換實體」擴充成 3-hop、4-hop
3/4-hop 鼓勵寫成多句、用代名詞串接
→
2. 說法改寫人工改寫（更具體／更籠統／否定）＋自動換字換實體
→ 做出不被支持的說法
→
3. 標註原本三類：SUPPORTED / REFUTED / NOT ENOUGH INFO
後兩類連受訓標註員都分不清 → 合併成 NOT-SUPPORTED

品質控管：只保留至少 3 位標註員意見一致的說法，Fleiss kappa = 0.63

④ 研究方法 · 關鍵技巧

怎麼「增加跳數」？替換實體

跳數說法（改寫示意）多查了哪篇
2-hopPatrick Carpentier 開 Ford Fusion，它是 2006 年式推出的Ford Fusion、Patrick Carpentier
3-hop把「Patrick Carpentier」換成「1997 年 CART 賽季年度新秀」＋ 1997 CART 賽季

每換掉一個實體，就要多查一篇才知道它是誰 → 跳數 +1。
重複一次就變 4-hop。

⑥ 實驗設計

資料規模與基準系統

資料

  • 共 26,171 則說法
  • train 18,171 / dev 4,000 / test 4,000
  • 平均長度：2/3/4-hop 為 19.0 / 24.2 / 31.6 tokens（FEVER 只有 9.4）

指標

  • 文件／句子檢索：EM、F1
  • 判斷：Accuracy
  • 整體：HoVer Score
  • 另抽 100 則請人類做，當對照

基準系統（仿 FEVER 頂尖系統）

1. TF-IDF（bi-gram）找文件
2. BERT 重新排序前 20 篇
3. BERT 從前 5 篇挑句子
4. BERT 做 NLI 二元判斷

注意：一次檢索到底，沒有迭代

⑧ 研究缺口與限制

還缺什麼？

作者自己指出的

  • 需要能做多跳推理的檢索方法
  • 3/4-hop 標註成本、時間、品質控管急遽上升，第一版只用了 12k 個 HotpotQA 例子

讀者可以再想的

  • 「被推翻」和「證據不足」合併了，系統分不出兩者
  • 只用英文 Wikipedia，不是開放網路
  • baseline 一次檢索到底，沒有迭代

總結 · 自我檢測

一句話記住這篇

HoVer 用「替換實體來增加跳數」造出最多 4-hop 的查核題，證明跳數越多、證據越難找齊，而瓶頸在檢索，不在判斷。

Q1. HoVer 為什麼把 REFUTED 和 NOT ENOUGH INFO 合併？

多跳說法中，連受訓標註員都分不清這兩類，所以改成二元分類。

Q2. 為什麼說瓶頸在檢索？

給完整證據時判斷有 81.2%，但整條流程完全做對只有 14.9%。

Q3. HoVer Score 跟一般準確率差在哪？

它要求每篇證據文件都至少找到一句證據，而且標籤也要對。
